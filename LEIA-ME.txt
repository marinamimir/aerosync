AeroSync — pasta pronta para publicar
=====================================

Esta pasta já é o site inteiro. Não precisa mudar nada.

OPÇÃO A — NETLIFY (mais rápido)
1. No computador, abra: netlify.com/drop
2. Arraste esta pasta (AeroSync_site) para a página.
3. Crie a conta grátis quando pedir, para o site não ser apagado.
4. Copie o link que aparecer (ex.: https://nome.netlify.app).

OPÇÃO B — GITHUB PAGES
1. github.com > "+" > New repository > nome "aerosync" > Public > Create.
2. "Add file" > "Upload files" > arraste TUDO o que está dentro desta pasta
   (aerosync.html, index.html, manifest.json, sw.js e a pasta icons) > Commit changes.
3. Settings > Pages > Source: "Deploy from a branch" > main > / (root) > Save.
4. Espere alguns minutos. O link fica: https://SEU-USUARIO.github.io/aerosync/

INSTALAR NO CELULAR
- Abra o link no celular.
- Android (Chrome): menu ⋮ > "Instalar app" (ou "Adicionar à tela inicial").
- iPhone (Safari): Compartilhar > "Adicionar à Tela de Início".

PASSAR PARA OS COLEGAS
- Mande só o link. Cada um instala do mesmo jeito e tem os próprios dados.

ATUALIZAR O APP DEPOIS
1. Troque o aerosync.html por um novo — mas lembre de manter o trecho
   "PWA: app instalável e offline" que está no <head>.
2. Abra o sw.js e troque CACHE_VERSION = 'v1' por 'v2' (depois 'v3', ...).
3. Publique de novo (arraste no Netlify ou faça upload no GitHub).

LEVAR SUAS MISSÕES PARA O CELULAR
- Computador: Ajustes > Exportar. Celular: Ajustes > Importar.
